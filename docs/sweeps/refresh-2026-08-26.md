## Not published — read this before assuming a gap is an absence

**Nigeria (TCSN) — PARTIAL.** The live register caps at 500 rows and serves no
Silver tier, so three claimed Silver→Gold upgrades could not be checked: Burna

**Asake "Bad Influence" 2× Platinum (NG) — HELD.** Reported by the register
read, but the recording could not be confirmed to exist under that title on any
music service. A plaque is not published for a release that cannot be found.

**Switzerland (hitparade.ch), Belgium (BEA/Ultratop)** — both behind Cloudflare
interactive challenges; nothing read.

**Australia (ARIA)** — the only list ARIA publishes is headed "current as of
31 August 2020" and has not moved in six years. Anything certified since is
invisible there. All 354 rows were read; only two Burna Boy featured credits
appear.

**Canada (Music Canada)** — the register is a JS/AJAX FacetWP widget whose
endpoint returns an empty array to every query tried. A later pass should drive
the real search input with typed keystrokes, a few artists at a time.

**Brazil (Pro-Música), Colombia, Sweden (IFPI Sverige), Ireland (IRMA)** — no
readable public register. For Sweden and Ireland that is not a failed load:
they publish no certification database at all.

Every one of these can only move totals **up**.
