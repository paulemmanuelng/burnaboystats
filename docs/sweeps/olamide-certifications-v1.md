# Olamide — every certification (body-side sweep)

**Method:** identical to the rest of this series — a certification counts when it
appears in the **issuing body's own register**, never in a press release, a fan
tally or a wiki. One plaque per title per country at its **current** tier (a 3×
Platinum is one plaque, not three; an upgrade replaces, it does not add).
**Lead, co-billed and featured credits all count**; writer and producer credits
do not. Singles and albums are recorded separately. A register read in full and
holding nothing is a **proven zero**; a register that could not be read is a
**gap**, never a zero. Swept **28 Aug 2026**.

## Total: **54 certifications**

**Country split:** 🇳🇬 NG 52 · 🇬🇧 UK 2

## Nigeria — read from the register's own archive, not its live page

TCSN's live register at `turntablecharts.com/certification` serves a hard cap of
**500 rows and no Silver at all**. The Nigerian rows here are taken from the
register's own **archived capture of 21 Feb 2026 — 2,477 rows**, read via
`__NEXT_DATA__` → `props.pageProps.certEntries`, which carries all 817 Silvers
the live page withholds. Olamide holds **52** Nigerian plaques:
**17 Platinum, 13 Gold, 22 Silver**.

Rows are keyed on **(title, artiste)**, never on title alone — the register
appends the primary artist in parentheses to separate colliding titles, and it
carries three different records called *On God*. A title-only match merges them.

## International

**Two**, both BPI (UK) **Silver** singles certified 07.08.2026 on his own YBNL Nation imprint: *Infinity* (credit `OLAMIDE FT OMAH LAY`) and *Amapiano* (credit `ASAKE FT OLAMIDE`).

**The collision that had to be avoided.** BPI title id `10277` — "INFINITY" —
covers four different singles: Jaymes Young (Gold), One Direction (Silver), Guru
Josh Project (**Platinum**) and Olamide ft Omah Lay (Silver). The register
disambiguates only by artist id, so a title-only match would have handed him Guru
Josh's Platinum. The row is pinned to artist id **6924**.

**Not double-counted.** `omah-lay-certifications-v1.md` carries the same
*Infinity* Silver on Omah Lay's side. Counting it for both artists is correct —
the board counts per artist — but it is one award, not two.

## Gaps — never to be read as zeros

- **ARIA (Australia)** publishes no searchable register. Its only public list is
  `aria.com.au/latest-accreditations`, whose own header reads *"Current as of 31
  August 2020"* — before every release at issue here.
- **IFPI Greece** — the Award column exists only inside the weekly chart file,
  which is overwritten. 34 archived captures (Jan 2025 → Mar 2026) hold nothing
  for him, but they do not cover 2021–2024, so this is absence from what was
  read, not a zero.
- **ČNS IFPI (Czechia / Slovakia)** — the tier prints inside a chart row, so only
  a currently-charting title is ever visible. A very weak negative.
- **Ultratop (Belgium)** and **GLF (Sweden)** — not reached.
- **Ghana's own bodies** — GHAMRO's host never completes a connection and MUSIGA
  has no DNS record. Whether Ghana operates a certification
  programme at all is unresolved.
