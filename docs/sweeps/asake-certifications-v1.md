# Asake — every certification (body-side sweep)

**Method:** identical to burnaboystats.com — a certification counts when it appears in the **issuing body's own register**; one plaque per title per country at its **current** tier (an 8× Platinum is one plaque, not eight); lead, co-billed and featured **artist** credits all count, writer/producer credits do not. A press announcement is not a register. Sweep run **19 Aug 2026** in two halves: Nigeria + Africa, and the non-African bodies. ✓ = seen in the issuing body's own live database. ✓ᴬ = confirmed in the body's own **archived** register (Wayback capture of the same URL, where the live page no longer serves the row).

## Award events vs plaques

Fan trackers and this file count two different things, and the Nigerian register is the only one in this sweep that exposes the difference as data.

**Plaque count (this file, and burnaboystats.com's convention): 79.** One plaque per title per country at its current tier. Burna Boy's 230 is counted the same way, so the two are directly comparable.

**Award-event count (the fan-tracker convention): every separate dated announcement counts.** *Terminator* was announced 4× Platinum in June 2023, then 5×, then 6×, then 7× — one plaque, four certifications by that convention.

The **21 Feb 2026** capture is the only TCSN state that publishes the ladder as separate dated rows rather than a current-tier snapshot: it carries the same title several times at different tiers under six different batch dates (2023-06-08, 2024-10-04, 2024-10-10, 2024-10-14, 2025-01-05, 2025-02-06). ## Removals

**Every row below is a claim that circulates and does not survive a register read. Each is deleted from the figures.**

- **🇳🇬 *Bad Influence* — Nigeria 2× Platinum. Removed on credit, not on existence.** The register row is real: the live register carries exactly one *Bad Influence* row — `Bad Influence | Asake | Platinum_2` — and archive capture `20251112103208` carries the same title credited to "Asake" at Platinum, dated 2025-01-05. **But no Asake recording of that title exists.** It is absent from *Mr. Money With The Vibe*, *Work of Art*, *Lungu Boy* and the *M$ney* tracklist, and from his singles. *Bad Influence* is **Omah Lay's** 2020 single, track 4 on the *Get Layd* EP. Decisively, the same 1,203-row capture carries **46 Omah Lay rows** including the rest of *Get Layd* ("You", "Lo Lo", "Damn", "Ye Ye Ye") under his own name, while listing no Omah Lay *Bad Influence* anywhere. This is a data-entry error in the register's `artiste` field — the same register spells Central Cee as "Centra Cee". **The 2× Platinum Nigerian plaque is genuine; it is not Asake's.** Publishing it here would put a false credit on the site and double-count against the Omah Lay sweep. *(This removal is why the Nigerian total reads 71 and not 72.)*
- **🇳🇬 *Mr. Money With The Vibe* — Nigeria 4× Platinum. Removed: the row does not exist.** Wikipedia's Asake discography claims it. It is in **no capture of the register, ever, at any tier**. Across all 22,813 row observations in every archived register state, **TurnTable has certified exactly one album in its history** — Wizkid's *Made in Lagos* (Gold), and only in the Feb 2023 captures. There is no *Work of Art*, no *Lungu Boy*, no *M$ney* row either. The register is a singles register in practice. This is not a low-confidence row; it is a row that does not exist.
- **🇿🇦 Any South African Asake plaque.** None is claimed on Wikipedia and none exists in RiSA's register — all 601 unique rows read, with a 14-row Wizkid control proving the query works.

## Known gaps

**Read this before quoting a zero. An unread register is a gap, not a zero.**

1. **🇧🇪 Belgium (Ultratop/BEA), 🇨🇭 Switzerland (IFPI CH), 🇬🇷 Greece (IFPI Greece) were NOT READ this pass.** Three national registers that hold plaques for other artists in this family were not queried. No Asake plaque is claimed in any of them — but none can be recorded as a zero either. Belgium and Switzerland matter concretely, because *Lungu Boy* charted in **both** (BE #167, CH #97 — see the chart file), which is exactly the profile a low-tier album plaque sits behind.
2. **🇪🇬 Egypt has an IFPI national group but no locatable certification register.** The MENA chart API and site were read and found to publish charts only. This is a **gap**: it cannot be said that Egypt holds no Asake plaque, only that no Egyptian register is publicly readable.
3. **The Nigerian count is a FLOOR, not a ceiling.** The programme is **request-based** — a label applies, so absence proves nothing about thresholds. The live register displays only 500 of what were 2,477 rows in February. Archive coverage between captures is uneven: a plaque awarded and later superseded between two captures would be invisible. Six Wayback HTML captures were crawler-truncated and only partly salvaged; each sits between two intact captures of the same register state, so no data is *believed* lost — **but that is an inference, not a proof.**
