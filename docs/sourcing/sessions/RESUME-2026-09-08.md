## Methods established today, reproducible

**Dark-mode regression checking, two ways, because they catch different things:**
1. *Rendered union diff.* Worktree at the baseline commit + a second dev server
   (`npx next dev -p 3101`; Turbopack rejects a symlinked `node_modules`, so
   `cp -Rc` it). Capture the SET of every computed colour per route from each
   side and diff. Catches a colour that appeared or vanished; **cannot** catch a
   value that merely moved to a different element.
2. *Mechanical per-site diff.* Regex every `color-mix(… var(--tok) N%)` in both
   revisions, compare multisets per file. This is what actually caught the two
   regressions, and it is now a permanent guard (`tests/mixStrengths.test.ts`).

Two measurement traps that produced false results, both worth remembering:
- `localStorage.theme` is per-origin, so the current server's iframes hydrated to
  the stored theme and re-wrote `data-theme` after the override. Set the theme
  BEFORE load and wait ~2.2s for the ThemeToggle effect.
- `getComputedStyle` mid-transition returns the animating value. Two "bugs"
  evaporated on re-measure: the skip link "never appearing" (it slides in over
  240ms) and a chip reading the wrong theme's gold.
