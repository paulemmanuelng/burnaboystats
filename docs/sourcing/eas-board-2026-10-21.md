## How it was read

- Page: https://chartmasters.org/best-selling-artists-of-all-time/ ("daily
  update"), fetched 21 Oct 2026 21:08 UTC; `last-modified` and JSON-LD
  `dateModified` 2026-10-21T17:31:46Z.
- robots.txt read first: `User-agent: *` allows `/` and, in its second group,
  explicitly allows `/wp-admin/admin-ajax.php`. Plain curl, user agent
  "burnaboystats-bot", no login, no cookies, nothing clicked. The Playcounts
  Tool was not fetched.
- The table is the chartmasters-data-table plugin (`data-table="artist_top_cspc"`,
  server-side, 25 rows a page, `data-total="706"`). Paged the way the page's own
  script does: POST `/wp-admin/admin-ajax.php`, `action=cm_data_table`,
  `table=artist_top_cspc`, `page=1…29`, `sort=rank`, `dir=asc`, the page's
  nonce. 21:09–21:11 UTC; every response reported `total: 706, pages: 29`.
- **Board size: 706.** g# runs 1–706 with no gaps; `#` equals g# unfiltered;
  sorting by Total EAS reproduces g# with 0 mismatches.
- Country by the board's own search (`country:<name>`): 67 country searches
  covering every African country and spelling variants, plus "africa". Only
  `country:nigeria` (and `country:niger`, a substring of it) returns African
  rows, the four below; `country:south` returns South Korea's 18; every other
  search returns none.
  `genre:afrobeats` returns those four plus Beéle. Controls (name plus
  country clause, one row each): Akon, DJ Khaled and French Montana
  `country:states`; Sade and Dido `country:kingdom`; Beéle `country:colombia`;
  Maitre Gims `country:france`.
- Identity by the Spotify id in each row's edit link against `app/data/spotify.ts`:
  the four match, and none of the file's other 19 ids is on the board.
