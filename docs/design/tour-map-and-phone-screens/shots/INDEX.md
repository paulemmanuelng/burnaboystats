# Screenshot index

Captured 29 Sep 2026 from the live site (https://burnaboystats.com) with `scripts/mobile-shot.mjs`; the files marked "30 Sep" were added or retaken on 30 Sep 2026 the same way. Phone = 390×844 CSS px at 2× (files are 780 px wide). Desktop = 1440×900 at 1×. The "1024 band" = 1024×768 at 1×. Theme is the site's own stored choice (dark unless marked light). Scrolled shots were scrolled instantly and then left to settle, so the scroll values in the file names are exact. The live site is the source of truth; if a shot and the live page disagree, the page wins.
